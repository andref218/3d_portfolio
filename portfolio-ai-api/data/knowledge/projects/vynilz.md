# Vynilz

## Overview

Vynilz is a full-stack web platform that reimagines how vinyl collectors manage and experience their records. It alows users to build, organize, and showcase their collections while creating a personalized collecting experience.

---

## Motivation

As a vinyl enthusiast, André wanted to combine one of his biggest passions with software development by creating a real-world product for the collector community.

The goal was to create an application that solved a real problem while allowing him to explore authentication, database design, third-party API integration, and scalable application architecture.

---

## Tech Stack

### Frontend

- Next.js Server Actions

### Authentication

- Google OAuth

### External Services

- Discogs API
- Cloudinary

### Deployment

- Vercel

---

## Key Features

- Personal vinyl collection management
- Discogs search and import
- Public collector profiles
- Achievement system
- Featured records
- Responsive design
- SEO optimization

---

## Technical Challenges

Some of the main challenges during development included:

- Integrating the Discogs API while maintaining a smooth user experience.
- Designing a scalable MongoDB data model for collections, achievements, and public profiles.
- Creating a responsive interface that worked consistently across desktop and mobile devices.
