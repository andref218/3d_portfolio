# YourJobs

## Overview

YourJobs is a full-stack job application tracker designed to help users organize and manage their job search through a modern Kanban-style interface. The application focuses on responsive design, and efficient job application management.

---

## Motivation

The project was built to explore modern Full-Stack development while solving a practical problem faced by many job seekers.

It provided an opportunity to gain hands-on experience with authentication, database design, reusable UI components, and building an interactive dashboard using Next.js.

---

## Tech Stack

### Frontend

- Next.js
- React
- Tailwind CSS
- Framer Motion

### Backend

- MongoDB
- Mongoose
- Better Auth

### Deployment

- Vercel

---

## Key Features

- Job application tracking
- Kanban-style dashboard
- Secure user authentication
- Create, edit, and delete job applications
- Responsive design
- Modern UI with animations

---

## Technical Challenges

Some of the main challenges during development included:

- Designing a flexible Kanban board for managing job applications.
- Implementing secure user authentication and session management.
