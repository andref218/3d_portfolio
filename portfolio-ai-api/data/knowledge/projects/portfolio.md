# Interactive Portfolio

## Overview

André's portfolio is more than a traditional showcase website. It combines interactive 3D experiences, modern web development, and Artificial Intelligence to create a more engaging way for visitors to explore his work.

Instead of simply reading project descriptions, visitors can interact with an AI assistant capable of answering questions about André's background, experience, skills, and projects.

---

## Motivation

The goal was to move beyond a traditional portfolio by creating an experience that better reflects André's interests in both Full-Stack Development and AI Engineering.

The project demonstrates not only completed work but also how AI can improve the way portfolios are explored and presented.

---

## Tech Stack

### Frontend

- React
- React Three Fiber
- Three.js
- Tailwind CSS

### AI

- Retrieval-Augmented Generation (RAG)
- FastAPI
- LangChain
- ChromaDB

---

## Key Features

- Interactive 3D portfolio
- AI-powered portfolio assistant
- Semantic search over a personal knowledge base
- Responsive design
- Modern user experience

---

## Technical Challenges

Some of the main challenges during development included:

- Combining a 3D interface with traditional web content.
- Designing a Retrieval-Augmented Generation system specifically for a personal portfolio.
- Building a knowledge base capable of answering questions naturally while remaining accurate.
