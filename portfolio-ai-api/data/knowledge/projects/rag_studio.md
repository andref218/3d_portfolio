# RAG Studio

## Overview

RAG Studio is a Retrieval-Augmented Generation (RAG) application that enables users to ask natural language questions about PDF documents using a local Large Language Model (LLM). By combining semantic search with retrieved document context, the application generates grounded answers while reducing hallucinations.

---

## Motivation

After studying Large Language Models and Retrieval-Augmented Generation, André wanted to build a complete RAG system from scratch to better understand every stage of the pipeline.

The project was designed as a hands-on learning experience, covering document ingestion, semantic retrieval, vector databases, prompt engineering, and response generation.
